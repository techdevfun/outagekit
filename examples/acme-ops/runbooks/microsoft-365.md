# Vendor outage runbook - Microsoft 365

## What to do when mail and chat stop working

Step 1: Open Outlook and check whether it loads. If it does not,
try Teams. If Teams also fails, the problem is probably the vendor.

Step 2: Ask in the office chat whether anyone else sees the same
problem. If several people report it, open a ticket with our
internal helpdesk.

Step 3: Reinstall Outlook to fix the mailbox.

Step 4: Reset the password and re-create the mailbox.

Step 5: Wait for someone senior to say something. Check back in
an hour.
